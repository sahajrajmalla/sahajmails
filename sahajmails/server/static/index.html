How it works

Wrap one sentence in an ai block. Everything outside it is byte-identical for every recipient — that is the point.

Hi {{ first_name }},

{% ai "opener" max_words=25 fallback="Hope your week is going well." %}
One warm sentence about {{ company }}. No greeting, no exclamation marks.
{% endai %}

The rest of my email is the same for everyone.

Plugins

Writing one

Publish a package that exposes a sahajmails.plugins entry point, or drop a .py file in your plugins folder and enable it below. A plugin runs with your full privileges — the same trust model as any pip install.
